## PR title
Add AGENTS.md working guide with package map, invariants, and testing notes

## Status
complete

## Summary
Adds `AGENTS.md` at the repo root so agents have one place to find the stack, entry points, package responsibilities, testing workflow, invariants, and key docs. Every claim was checked against the code, and three details in the task spec turned out to be wrong; the doc follows the code. (1) The SQLite driver is `github.com/mattn/go-sqlite3`, which needs CGO, not `modernc.org/sqlite`. (2) Some raw SQL already lives outside `internal/storage/`, in `cmd/prov/commands.go` and `internal/correlation/correlation.go`. The doc treats these as legacy exceptions and says not to add more. (3) The `redaction_rules` table and the `redaction` config exist, but nothing applies redaction on the write path yet. The doc says so explicitly, so agents don't assume stored data is already redacted.

## Changes
- New `AGENTS.md`, covering:
  - Stack and entry points: the CGO SQLite driver, golang-migrate, single `cmd/prov` binary, socket/DB paths, WAL mode, the `AI_PROVENANCE_HOME` override.
  - Package map table.
  - Testing: `go test`, `-race`, gofmt/vet, the lint step CI runs, temp-dir rules, `server_test.go` as the pattern for new tests, flaky-test notes.
  - Invariants: append-only `prompt_events`, immutable numbered migrations, DB access through storage, embedded hook templates and reinstalling them, hooks fail silently, redaction.
  - Doc signposts: README, ROADMAP, DESIGN, TESTING, CHANGELOG, migrations.

## Testing
This is a documentation-only change. `~/.runner/hooks/verify-completion.sh` passes (build, vet, gofmt). I ran `go test -race -count=1 ./...` several times, before and after the change: some runs passed fully, and others had one intermittent failure that was already there on the unmodified tree (`TestCaptureHookUserPrompt` / `TestCaptureHookToolUse` in `cmd/prov` timing out with "Event not found in database within timeout", once `TestDaemonStartAndBind`). Each of these passes when run alone.

## Needs human attention
- The acceptance criterion "`go test -race ./...` passes" holds only intermittently because of the existing flaky tests above. This change doesn't cause or affect them. Other worktrees running tests on the same machine at the same time may make it worse.
- The task spec named `modernc.org/sqlite` (pure Go). The repo actually uses `mattn/go-sqlite3` (CGO). If moving to modernc is intended, that is a separate change.
